Trois étapes pour entrer dans la Chronique. Tu peux revenir en arrière à tout moment.

  1. Crée ton personnageChoisis ta voie énergétique — Vital, Spirituel, Arcanique ou Occulte.

Chronique des jets

Comment remplir une fiche ?
  • Le Flux n'est pas une classe : c'est une voie énergétique. Deux personnages du même Flux peuvent être totalement différents.
  • Caractéristiques : le petit nombre sous chaque score est le modificateur — clique-le pour lancer un d20 + ce modificateur.
  • Réserve de Flux : l'énergie que coûtent tes techniques. Contrôle : à surveiller si tu joues le Flux Occulte.
  • Faiblesses : obligatoires. Même les personnages puissants ont des limites (§16).
  • Publier à la table rend ta fiche visible aux autres joueurs au prochain partage.

Tes fiches

Comment se servir du plateau ?
  • Choisis une carte dans la colonne de gauche — les 22 lieux d'Astréïa sont déjà là.
  • Pose des pions : « + Mon personnage » pour toi, « + PNJ » pour tout le reste.
  • Déplace un pion en le glissant ; le nombre de cases parcourues s'affiche.
  • Navigue : glisse le fond pour bouger la vue, molette pour zoomer, « Recentrer » pour tout revoir.
  • Le plateau est commun à toute la table. Clique « Partager la table » en haut pour que les autres voient tes changements.

Initiative

À quoi sert le Codex ?
  • C'est le livre du monde, commun à toute la table : le lore d'Astréïa y est déjà écrit.
  • Le Gardien peut modifier n'importe quelle entrée et en ajouter.
  • Toute entrée rangée dans Flux apparaît automatiquement dans le menu des fiches — c'est comme ça qu'on ajoute une voie énergétique.
Le Codex est pré-rempli avec le lore d’Astréïa. Le Gardien peut tout modifier, et ajouter de nouveaux Flux.
Comment fonctionne le partage ?
  • Ce qui est commun à la table : les cartes et leurs pions, l'initiative, le Codex, et les personnages que chacun publie.
  • Ce qui reste à toi seul : ton compte, tes fiches non publiées et tes jets — ils vivent dans ce navigateur.
  • « Partager la table » republie la page : toutes les vues ouvertes basculent sur ta version en quelques secondes.
  • Si deux personnes partagent en même temps, la dernière gagne — préviens sur Discord avant de partager en pleine scène.
  • Sans droit d'écriture sur cet artifact, tu es en lecture seule : tu joues normalement, mais tes changements restent chez toi.
